# 🐋 泠鸢bot · QQ 群机器人

> 拟人化 QQ 群聊机器人 · **零 npm 依赖**（纯 Node 22+ 手写全链路）· QQ 官方机器人 API
> v2 大版本：新增知识库、语音双向、联网搜索、插件系统等 12 项能力（2026-10-22）

一个「该说话时说话、不该说话时真沉默」的群聊机器人：甜系傲娇鲸鱼娘人设、三层决策省钱架构、
链接自动解析、识图、反编造闸门、网页控制台——以及 **v2 新增的知识库 RAG / 上下文记忆持久化 /
语音双向 / 工具直答 / 联网搜索 / 插件系统 / 定时播报 / 群级限流**。

---

## 它是什么

- **不是又一个套壳聊天机器人**：完整手写了 鉴权 → WebSocket 长连接 → 事件分发 → 分层决策 →
  模型调用 → 限流 → 发送 → 容错 的每一段（零第三方依赖，只用 Node 内置模块）
- **省钱是第一设计目标**：三层决策（L0 正则 / L1 便宜判断 / L2 生成）+ 预算双闸 +
  提示词缓存优化，实测 **约 ¥1.6/天**
- **拟人是第一体验目标**：会吐槽、会沉默、会复读、会挑图——但事实类问题绝不为"换个说法"改答案

## 功能总览

### 💬 对话与人格

- **拟人人格**：鲸鱼娘「泠鸢bot」，会吐槽、用括号写动作；不该说话时真的沉默
- **助手模式**：暗号 `ovo` 切换精准回答（保留人设、关闭反重复与冷却，日额度仍生效）
- **反编造**：知识闸 + 回复硬闸，不知道就说不知道，不许编人名/年份/价格
- **情绪观察器**：26 类 / 240 词本地词典，只观察不注入提示词
- 🆕 **分群人格**（`#rg`）：每个群可以切不同人设，互不影响；`#rg 重置` 恢复全局

### 🆕 v2 新增（2026-10-22，借鉴 AstrBot）

| 功能 | 说明 | 入口 |
|---|---|---|
| **知识库 RAG**（kb.js） | 主人把"该知道的"写成条目落盘，模型说"不知道"时自动检索注入资料——事实以资料为准，人设照常演。字符 2-gram 检索，零依赖 | `#kb 关键词` 查询 / `#kb+ 标题\|内容` 添加 |
| **上下文持久化 + 自动压缩**（contextstore.js） | 重启不丢群聊记忆；被挤掉的旧消息自动用小模型压成 ≤120 字摘要注入——旧话题不断片，token 可控 | 自动运行 |
| **语音双向**（tts.js / stt.js） | 文字回复可跟一份语音（**免费 Edge TTS 兜底**，无需任何 Key）；语音消息自动转文字进对话（需配一个 OpenAI 兼容 STT 接口） | `#yy` 开关 / `#sy 文本` 朗读 |
| **工具直答**（tools.js） | 算式 `1+2*3等于多少` 代码直答（**0 成本、永不错**）；`XX的天气` 走 wttr.in 免 Key 直答 | 自动识别 |
| **联网搜索**（search.js） | `搜一下 XX` → DuckDuckGo（必应兜底）搜完把结果交给 L2 用人设说——补"知识截止"短板 | `搜一下 XXX` |
| **插件系统**（plugins.js） | 往 `server/plugins/` 丢一个 `.js` 文件即上线新指令，不用改主代码；自带冷却与主人保护 | 见 `plugins/example-hello.js` 模板 |
| **定时播报**（scheduler.js） | 每日定时主动消息（受官方月度主动消息额度限制，失败不重试） | `#定时 09:30 内容` |
| **群级限流 + 敏感词前置**（mod.js） | 群里炸锅时机器人不跟着刷屏（默认 15 条/分钟，超了静默冷却）；敏感词在**发送前**替换成＊ | 面板 `/x` 页配置 |
| **WebUI 扩展页** | 面板同端口 `/x?p=密码`：8 个新模块状态、按群限流、敏感词管理、定时任务一览 | 浏览器打开 `/x` |

## 架构

**三层决策**（brain.js）：

| 层 | 干什么 | 成本 |
|---|---|---|
| L0 | 硬规则（纯正则）：开关机、限流、寒暄、日期/算式/解码直答 | 0 |
| 🆕 工具闸 | 算式 / 天气 / 明确搜索，插在 L1 之前 | 0 ~ 1 次搜索 |
| L1 | 小模型判断"该不该接话" | 极低 |
| L2 | 生成（人设 + 上下文 + 摘要 + 资料注入 + 分段） | 主要成本 |

**消息管线**（index.js）：去重 → 指令/插件 → 开关机 → 复读 → 识图 → 🆕语音转写 → 链接解析 →
L0 → 工具闸 → 🆕群级限流 → L1 → 知识闸（🆕资料库检索）→ L2 → 回复硬闸 → 🆕敏感词过滤 → 发送 →
🆕（语音模式下跟发语音）

**核心模块**：`gateway.js`/`auth.js`（长连接与鉴权）· `brain.js`（三层决策）· `budget.js`（双预算
¥3/天、¥50 总额）· `qqapi.js`/`qqmedia.js`（发送与富媒体）· 🆕`kb.js` · 🆕`contextstore.js` ·
🆕`tools.js` · 🆕`search.js` · 🆕`tts.js` · 🆕`stt.js` · 🆕`persona.js` · 🆕`plugins.js` ·
🆕`scheduler.js` · 🆕`mod.js`

**设计铁律**：零依赖（只用 Node 内置）；能不用模型解决的就不用模型；每个新模块独立降级——
坏了只跳过那块，绝不影响主聊天管线。

## 快速开始

> 📘 **完整部署教程（含买服务器避坑、安全组配置、v2 新功能验证清单、旧版升级流程）见 [部署教程.md](部署教程.md)**。下面是极简版。

### 环境

- **Node 22+**（需要全局 `WebSocket`）
- 一台能联网的服务器（2核2G 起步）
- 一个 [QQ 机器人](https://q.qq.com) 应用（AppID / AppSecret）
- 一个 **DeepSeek** API Key（模型：`deepseek-flash` 默认能识图 / `deepseek-v4-pro` 纯文本）
- 🆕 可选：OpenAI 兼容 **TTS/STT** 接口（不配则语音回复走免费 Edge TTS、语音转写自动跳过）
- 可选：`chrome-headless-shell`（只有抖音视频解析需要，纯二进制非 npm 包，见 `deploy.sh`）

### 部署

```bash
# ① 本地：上传到服务器
scp -r deploy.sh server root@<服务器IP>:/root/lingyuanbot-upload/

# ② 服务器：一键部署（依次问 AppID / AppSecret / API Key / 日志页密码）
sudo bash /root/lingyuanbot-upload/deploy.sh
```

脚本自带**部署自检**（逐个解析 require + 全文件语法检查，少文件即中止）。

**跑完后两件事只能本人做：**

1. **群主**在手机 QQ 群设置 → 机器人 → 打开「**获取群内全部消息**」（否则免 @ 功能全废且不报错）
2. 设**主人**：群里发句话 → `sudo node /opt/lingyuanbot/tools/ops/find-openid.cjs` →
   把 32 位 `member_openid` 写进 `.env` → 重启（**不能填 QQ 号**，平台只发 openid）

**🆕 v2 功能启用：** 新功能无需额外配置，部署即生效。可选增强：`.env` 里配
`STT_BASE_URL / STT_API_KEY / STT_MODEL`（语音转文字）、`TTS_BASE_URL / TTS_API_KEY / TTS_MODEL`
（更高质量 TTS）、`AI_FALLBACK_MODELS=deepseek-v4-pro`（模型过载自动降级链）。

### 🔴 必踩的坑

| 坑 | 正解 |
|---|---|
| 主人标识填 QQ 号 → 主人规则静默失效 | 必须填 `member_openid`，用 `tools/ops/find-openid.cjs` 挖 |
| Windows CRLF 污染 `.env` | 用 `printf \| sudo tee` 写入，别用 nano 粘贴 |
| 只放行 SSH 端口 → 面板打不开 | 云控制台入方向放行 `8080`（机器人本体不需要任何入站端口） |
| 群里不 @ 就不回 | 群主开「获取群内全部消息」，不是代码问题 |
| 🆕 Edge TTS 偶发连不上 | 自动冷却 10 分钟后重试；语音失败时文字回复照常发，不影响使用 |

## 已知限制

| 限制 | 说明 |
|---|---|
| 抖音 >60 秒视频不发本体 | 只留无水印直链（省流量） |
| 检测不到「戳一戳」 | 官方平台不推该事件 |
| 不可真 @ 别人 | QQ 不暴露用户 openid |
| 私聊不发视频 | 单聊富媒体端点未做 |
| ~~上下文重启清空~~ | ✅ **v2 已解决**（contextstore.js 落盘 + 摘要） |
| ~~知识截止 2025 年中~~ | ✅ **v2 大幅缓解**（`#kb+` 喂知识库 + 联网搜索；模型内置知识截止仍在） |
| QQ 群聊默认收不到语音 | 官方平台限制；收到音频附件时 STT 自动工作，收不到则静默跳过 |
| 定时播报受官方主动消息月度额度限制 | 失败不重试；任务别加太多（上限 10 条/群） |
